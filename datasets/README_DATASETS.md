# 📊 Dataset Setup Guide for Toxic Comment Classification

## Overview
This directory contains dataset management tools and instructions for working with toxic comment data.

## 📁 Directory Contents

- `dataset_manager.py` - Python module for loading and managing datasets
- `sample_dataset.csv` - Sample dataset for testing (generated by running `python dataset_manager.py`, not checked into git)
- `dataset_info.json` - Dataset statistics and metadata (generated alongside the sample dataset)
- `train.csv` / `test.csv` - Full Jigsaw dataset (download separately, see below — not checked into git)

## 🚀 Quick Start

### Option 1: Use Sample Dataset (Immediate Testing)
```python
from dataset_manager import ToxicCommentDatasetManager

manager = ToxicCommentDatasetManager()
df = manager.load_sample_dataset()
manager.print_dataset_summary(df)
```

### Option 2: Download Full Jigsaw Dataset

#### Method A: Kaggle API (Recommended)
1. Install Kaggle API:
   ```bash
   pip install kaggle
   ```

2. Setup Kaggle API credentials:
   - Go to https://www.kaggle.com/account
   - Click "Create New API Token"
   - Save `kaggle.json` to `~/.kaggle/` (or `C:\Users\{username}\.kaggle\` on Windows)

3. Download dataset:
   ```bash
   cd toxic_comment_classification/datasets
   kaggle competitions download -c jigsaw-toxic-comment-classification-challenge
   unzip jigsaw-toxic-comment-classification-challenge.zip
   ```

#### Method B: Manual Download
1. Visit: https://www.kaggle.com/c/jigsaw-toxic-comment-classification-challenge/data
2. Download `train.csv` and `test.csv`
3. Place files in `toxic_comment_classification/datasets/`

## 📋 Dataset Information

### Jigsaw Toxic Comment Classification Dataset

**Source**: Kaggle Competition - Jigsaw Toxic Comment Classification Challenge

**Description**: 
- ~160,000 comments from Wikipedia's talk page edits
- Each comment is labeled across 6 toxicity categories
- Multi-label classification problem

**Labels**:
- `toxic` - General toxicity
- `severe_toxic` - Severely toxic content
- `obscene` - Obscene language
- `threat` - Threatening language
- `insult` - Insulting content
- `identity_hate` - Identity-based hate speech

**Format**:
```
id,comment_text,toxic,severe_toxic,obscene,threat,insult,identity_hate
000000...,Comment text here,0,0,0,0,0,0
000001...,Another comment,1,0,1,0,1,0
```

### Sample Dataset

When the full dataset isn't available, the system automatically creates a sample dataset with:
- 20 diverse comment examples
- Balanced representation of toxicity types
- Realistic comment patterns
- Proper label distribution

## 🛠️ Using the Dataset Manager

### Basic Usage
```python
from datasets.dataset_manager import ToxicCommentDatasetManager

# Initialize manager
manager = ToxicCommentDatasetManager()

# Load dataset (tries full dataset first, falls back to sample)
df = manager.load_or_create_dataset()

# Print comprehensive summary
manager.print_dataset_summary(df)

# Prepare data for training
X_train, X_test, y_train, y_test = manager.prepare_training_data(df)

# Get class weights for imbalanced data
class_weights = manager.get_class_weights(y_train)
```

### Advanced Features
```python
# Validate dataset integrity
validation_results = manager.validate_dataset(df)
print("Validation passed!" if all(validation_results.values()) else "Dataset issues found")

# Create detailed summary
summary = manager.create_dataset_summary(df)
print(f"Dataset has {summary['total_samples']} samples")

# Save dataset metadata
manager.save_dataset_info(df, "my_dataset_info.json")
```

## 🔧 Troubleshooting

### "Dataset not found" error
- Ensure you've downloaded the dataset files
- Check file paths match expected locations
- Use sample dataset for initial testing

### Memory issues with large dataset
- Consider loading data in chunks
- Use data sampling for initial development
- Ensure sufficient RAM available

### Kaggle API issues
- Verify API token is correctly placed
- Check internet connectivity
- Ensure competition rules are accepted on Kaggle

## 📞 Getting Help

If you encounter issues:
1. Check the validation results from `validate_dataset()`
2. Review the dataset summary for anomalies
3. Try the sample dataset first to verify code works
4. Check file permissions and paths
